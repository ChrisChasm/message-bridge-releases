Install once.
Get updates in the app.

Download Message Bridge, move it to Applications, and connect your Mac to Messages. No GitHub account or access token is needed.

Before you start: You need an Apple silicon Mac (M1 or later), macOS 26 or later, and Messages already signed in and working. Check Apple menu → About This Mac. Intel Macs and older macOS versions are not supported by this build.

1. Download and install

  1. Use the download button above to save MessageBridge.zip. On GitHub's release page, the same file is under Assets. Do not choose “Source code.”
  2. Double-click the ZIP in Downloads. Drag Message Bridge.app into Applications.
  3. Open Message Bridge from Applications. If macOS asks whether to open an app downloaded from the Internet, choose Open. If it instead says the developer cannot be verified, the app is damaged, or malware was detected, stop and ask your administrator for the correct release.

You do not need Xcode, Terminal, Python, or Node. Closing the window leaves the app running in the menu bar. Click its two-speech-bubble icon to reopen it.

2. Connect this Mac to Messages

  1. Open Setup & Settings. Click Open Full Disk Access. In System Settings, enable Message Bridge. If it is missing, use the + button to add it from Applications. Quit and reopen Message Bridge if macOS requests it.
  2. Click Verify access. Allow Message Bridge to control Messages when prompted. You can review this under System Settings → Privacy & Security → Automation → Message Bridge → Messages. This access check does not send a message.
  3. Under Sending account, select the Messages account you intend to use. Confirm the account belongs to you. Contacts access is optional.
  4. If macOS requests Keychain access for MessageBridgeKeychain, the helper inside Message Bridge, approve it. Always Allow avoids repeated requests for the same helper. Enter your Mac password only in the macOS prompt. This protects your local app data and AI connections; software downloads do not need a token.
  5. Optionally enable Start Message Bridge at Login, then choose Complete setup or Apply startup setting.

3. Connect your AI app

  1. Open AI Clients and select your client, such as Codex Desktop, Claude Desktop, Cursor, or LM Studio.
  2. Follow that client's setup card to install its connection. Restart or reconnect the AI client when instructed.
  3. Choose Copy setup prompt and paste it into your AI client. It checks the connection without sending a message. Look for Connected in Message Bridge.

Each Mac keeps its own account, history, and client connections. Do not copy another teammate's app data or credentials. Before normal use, agree on one controlled recipient and explicitly confirm the message in your AI app.

4. Get updates

  1. In Setup & Settings → Software updates, enable Check daily for updates. Checks run while Message Bridge is open and the Mac is available. A check may run shortly after launch when one is due.
  2. Click Check for Updates… for an immediate check. The same command is in the menu bar dropdown.
  3. When an update is available, follow its download/install prompt. You choose when to install. Installation waits for active sends to finish, then the app relaunches.
  4. Check the new version/build in Software updates. Your settings and saved history stay on this Mac. Reconnect your AI client if needed.

If you skip a version, a manual check lets you reconsider. Settings also shows the last successful check and a link to release notes. No account, password, token, or terminal command is needed to download updates.

If something needs attention

What you seeWhat to do
Download page says 404The first release may not be published yet. Ask your administrator. You do not need to sign into GitHub.
Update check did not completeCheck your Internet connection and open the download page. Try again later if GitHub is unavailable.
Wait for the current sendUnlock your Mac, let the send finish, and check again. Updates do not retry interrupted sends.
Cannot open or install an updateConfirm macOS 26+ and Apple silicon, that the app is in Applications, and that your Mac permits replacing it. Ask your administrator if the signed release is still rejected.
AI client needs attention after restartReconnect the client and run its setup prompt again. Do not resend an earlier message just to test the connection.

Manual recovery

If in-app updates cannot run, quit Message Bridge, download the latest signed MessageBridge.zip, and replace only Applications → Message Bridge.app. Reopen it and verify access. Keep the app's saved data and Keychain items. Ask your administrator before downgrading.

When asking for help, include your macOS version, Message Bridge version/build, and the exact error. Do not share AI credentials or private message history.
