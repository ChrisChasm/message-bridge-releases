# Message Bridge for Mac

Connect your local AI apps to Apple Messages on your Mac.

**Apple silicon (M1 or later) · macOS 26 or later**

## Download

[**Download Message Bridge**](https://github.com/ChrisChasm/message-bridge-releases/releases/latest/download/MessageBridge.zip) · [Release notes](https://github.com/ChrisChasm/message-bridge-releases/releases/latest)

No GitHub account or access token is needed. If the latest-release link returns 404, the first release has not been published yet.

## Install

1. Download **MessageBridge.zip** and double-click it to extract the app.
2. Drag **Message Bridge.app** to **Applications**, then open it there.
3. In **Setup & Settings**, grant **Full Disk Access** and **Automation → Messages** when prompted. Choose **Verify access**, then select your Messages sending account.
4. In **AI Clients**, install your client's connection, restart/reconnect that client, and use **Copy setup prompt** to check it without sending a message.
5. Under **Software updates**, enable **Check daily for updates**, or choose **Check for Updates…** whenever you want.

The app stays in the menu bar when you close its window. You choose when to install updates; installation waits for active sends and preserves your settings and history.

[Download the detailed installation guide](https://raw.githubusercontent.com/ChrisChasm/message-bridge-releases/main/TEAM-INSTALLATION.html) and open the saved HTML in your browser. The same guide is bundled in the app and attached to releases.

If macOS rejects the download as damaged or unverified, contact your team administrator. Do not bypass the warning. Each Mac needs its own Messages permissions and AI connections.

## Recovery

Quit Message Bridge, download the latest signed ZIP, replace only the app in Applications, and reopen it. Keep the saved app data and Keychain items. Ask your administrator before downgrading or retrying an interrupted message.

This repository contains public app downloads and documentation. Application source is maintained separately. GitHub's automatically generated “Source code” archives contain this distribution documentation, not the app; download **MessageBridge.zip**.
